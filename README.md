# Daysi Cunha — Presença Digital Estratégica

Site profissional de Daysi Cunha, desenvolvido em HTML, CSS e JavaScript puro.
O projeto apresenta serviços, processo, artigos e cases com foco em estratégia,
UX/UI, front-end e presença digital.

## Destaques

- Landing Page Estratégica
- Site Institucional Estratégico
- Processo orientado por diagnóstico
- Case real da Tornearia Barbosa
- SEO técnico básico, Open Graph, sitemap e dados estruturados
- Layout responsivo e navegação acessível

## Estrutura

- `index.html` — página inicial
- `solucoes.html` — serviços
- `processo.html` — processo de trabalho
- `cases.html` — portfólio e estudos de caso
- `cases/tornearia-barbosa.html` — case da Tornearia Barbosa
- `blog.html` — artigos
- `sobre.html` — apresentação profissional
- `contato.html` — diagnóstico inicial via WhatsApp
- `assets/` — estilos, scripts e imagens

## Visualização local

Abra `index.html` diretamente no navegador ou use um servidor HTTP local:

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Configuração

Os dados de WhatsApp e redes sociais ficam em `assets/js/site-data.js`.
As URLs canônicas consideram o domínio `https://daysicunha.com.br/`.

## Publicação

O conteúdo deste repositório deve ser publicado na raiz de `public_html` da
Hostinger. O domínio precisa permanecer com HTTPS ativo e apontar para a pasta
em que está o arquivo `index.html`.

[Tornearia Barbosa](https://tornearia-barbosa.vercel.app/) — site institucional
